# Extremes: Balanced

Promo page for a Glyphs 4 script that puts nodes on extremes, removes diagonal nodes, balances handles (Tunni) and harmonizes curvature across nodes (Green Harmony), with a closeness slider from 1:1 to By eye.

Page: https://nnedashkovsky.github.io/extremes-balanced/

All figures and drawings on the page were computed by the script itself on Hint Vintage Italic ExtraBold (O, P, C).
